Project Description

Pizza Sales Analysis Using SQL

This project analyzes a pizza sales database using SQL to extract meaningful business insights. It demonstrates the use of SQL concepts such as JOINs, Aggregate Functions, GROUP BY, ORDER BY, Common Table Expressions (CTEs), Window Functions, and Subqueries to solve real-world business problems.

The analysis is divided into three levels:

Basic Analysis: Calculated total orders, total revenue, highest-priced pizza, most popular pizza size, and top-selling pizza types.
Intermediate Analysis: Analyzed sales by pizza category, order distribution by hour, category-wise pizza distribution, average daily orders, and top revenue-generating pizzas.
Advanced Analysis: Calculated revenue contribution by pizza type, analyzed cumulative revenue over time, and identified the highest revenue-generating pizzas within each category.
Key Skills Demonstrated
SQL Joins
Aggregate Functions (SUM, COUNT, AVG)
GROUP BY and ORDER BY
Common Table Expressions (CTEs)
Window Functions
Subqueries
Business Data Analysis
Revenue and Sales Reporting
Project Objectives
Analyze customer ordering patterns.
Identify the best-selling pizzas and categories.
Calculate revenue and sales performance.
Generate business insights to support data-driven decision-making.

This project is suitable for showcasing SQL proficiency and practical data analysis skills in a portfolio for Data Analyst, Business Analyst, or SQL Developer roles.
